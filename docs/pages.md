# 页面与可视化设计

## 导航原则

默认进入 Today，优先呈现「现在做什么、今天还剩多少」。首页上方同时呈现当前项目阶段摘要，下面可展开整体进度；目标与项目视图展示完整阶段轨迹。所有视图共用同一批真实数据，初始为空，不插入虚构项目。

## 页面结构

| 页面 | 信息层级与主要操作 |
| --- | --- |
| Today / 今日 | 日期与快速新增；今日完成/剩余/计划时长概览；时间顺序任务；昨日遗留；临近截止；提醒 |
| Calendar / 日历 | 日、周、月切换；回到今天；上一/下一周期；全天和时段安排；点击编辑、拖动改期、拉伸调整时间 |
| Tasks / 任务 | 任务清单、筛选与创建；状态、优先级、所属项目、依赖、日期、截止；完成、延期、取消、删除 |
| Goals & Projects / 规划 | Goal → Project → Milestone 结构；用户状态与完成比例；当前阶段、阶段日期、下一节点；层级编辑 |
| Routines / 重复任务 | 规则名称、重复频率、起止日期、时间和启停状态；新增/编辑；前序 Routine 与偏移天数 |
| Daily Review / 每日回顾 | 选择日期；实际时间、精力、笔记和项目分钟分配；当天任务完成/未完成快照 |
| Dashboard / 统计 | 今日/本周完成数、范围完成率、计划/实际小时数、项目时间分布、临近截止 |
| Settings / 设置 | 时区、默认开始时间、通知权限说明、数据导出、集成能力状态 |

页面使用同一 Next.js 入口和可分享的 hash 导航：`/#today`、`/#calendar`、`/#tasks`、`/#goals`、`/#routines`、`/#review`、`/#dashboard`、`/#settings`。刷新保留所处页面，浏览器前进/后退可切换视图。

## 今日视觉规则

- 任务标题和开始时间为第一视觉层级，项目、里程碑和预计时长为辅助信息。
- 通过清晰的时间轴/任务行表达先后；无时间的任务独立展示，保留用户优先级。
- 完成环、完成数量与剩余数量使用同一统计口径；无任务时显示可操作空状态，不显示虚假 100%。
- 完成任务有明确视觉区分，可查看和重新打开，不从历史消失。
- 昨日遗留列出改到今天、选择日期、取消、保持逾期动作；不给用户悄悄增加今天任务。
- 使用目标颜色帮助辨认归属，同时保留名称和状态文字，不能只依赖颜色表达含义。

## 整体进度视觉规则

- Goal / Project 展示任务完成数 / 总数、进度条和用户维护的状态。
- Milestone 按起始/截止日期排序显示阶段轨迹；当前阶段为最早尚未完成的阶段，并展示后续节点。
- 任务完成比例为「已完成 / 未取消且未删除任务」，它不代表剩余真实工作量，也不会预测毕业、考试或求职成功率。
- 长期目标尚未拆任务时显示「尚未拆分任务」，不能把空分母解释为完成。
- 计划与实际小时分别呈现；实际项目分布只用用户记录的分配分钟，未分配部分明确标注。

## 表单与交互

新增和编辑使用集中表单，展示必要字段与关联选择；时间/日期错误直接反馈。拖动或变更状态先请求后端，失败则恢复原位置或提示刷新；并发版本冲突不能静默覆盖。

删除与取消区分：取消保留在状态记录中；删除隐藏任务但保留数据库去重与历史依据。删除 Goal / Project / Milestone 若仍有引用，应呈现具体阻止原因。

桌面侧边导航与移动屏宽自适应；卡片、表格和日历避免水平溢出。按钮有可辨认文案和可聚焦状态，弹窗支持关闭，保存中防止重复提交。
